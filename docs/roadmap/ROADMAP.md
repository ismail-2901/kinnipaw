# Roadmap — KINNIPAW

The complete product scope is planned, but implementation is milestone-based. Native mobile foundation starts in M1; M9 is integration, feature parity and release readiness, not the first time mobile work begins.

| Milestone | Scope | Preserved task IDs |
|---|---|---|
| **M0** | Product discovery and documentation foundation | `PB-001–PB-008` |
| **M1** | Monorepo, web/mobile skeleton and infrastructure | `PB-009–PB-022` |
| **M2** | Authentication, users and pet management | `PB-023–PB-031` |
| **M3** | Social community | `PB-032–PB-041` |
| **M4** | Responsible adoption | `PB-042–PB-050` |
| **M5** | Lost-and-found and rescue | `PB-051–PB-061` |
| **M6** | Messaging, notifications, care and providers | `PB-062–PB-074` |
| **M7** | Admin and moderation | `PB-075–PB-084` |
| **M8** | AI assistance and matching | `PB-085–PB-093` |
| **M9** | Web/mobile integration and native release readiness | `PB-094–PB-106` |
| **M10** | QA, security and launch | `PB-107–PB-120` |


## Suggested sequencing

- M0 must pass documentation audit before schema/code generation.
- M1 establishes a working web and mobile skeleton and CI.
- M2/M3 prove identity, animal profiles and community value.
- M4/M5 implement the highest-impact adoption/lost-found/rescue workflows.
- M6/M7 add communication, care and governance.
- M8 adds optional AI only after deterministic workflows exist.
- M9 closes mobile parity and store-readiness gaps.
- M10 completes independent QA, security, performance and beta launch.

## Timing

A prior planning estimate was roughly 14–18 weeks for a solo AI-assisted build, but this is not a guarantee. The scope is large; actual duration depends on available hours, learning curve, integrations, review and rework. Never sacrifice security/quality to hit a calendar estimate.
