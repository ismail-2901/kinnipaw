# Source Archive 07 — UI, Mobile, AI and Operations

## UI

- Premium, warm, modern, accessible visual identity.
- Suggested warm ivory `#FAF9F6`, sage `#66856C`, terracotta `#D98769`, charcoal `#252A27`, neutral `#E8E6E0`.
- Geist + Noto Sans Bengali direction.
- Desktop left navigation, central feed/listings and optional useful right rail.
- Mobile bottom navigation: Home, Explore, Create, Rescue, Profile.
- Responsive test widths: 360, 390, 768, 1024, 1440 px.
- Loading, empty, error, success, permission-denied and retry states.
- Accessibility: keyboard, contrast, alt text, reduced motion and readable Bangla.

## Mobile

- React Native + Expo + Expo Router.
- Shared contracts/types/design tokens.
- Native camera/photo picker, push, deep links and secure auth storage.
- Low-connectivity behaviour and safe caching.
- Web and mobile share backend business logic.

## AI

- Pet care educational assistant, no diagnosis/prescription.
- Lost/found rule-based matching first; optional visual similarity later.
- Explainable adoption suggestions.
- Listing text assistance; user approves.
- Moderation risk flags; human decides.
- Rate limits, quotas, timeout, data minimization, server-only keys and provider-term review.

## Operations

- GitHub Actions CI.
- Local/development/staging/production separation.
- Supabase free tier for prototype with current quota verification.
- Vercel Hobby only for non-commercial personal preview under applicable terms.
- Commercial hosting must explicitly permit commercial use.
- Expo EAS quotas and store fees/rules must be checked at release time.
- Backups, restore tests, monitoring, privacy, ToS and Community Guidelines before public launch.
