# Prompt 10 — Milestone Completion Review

```text
Review the current KINNIPAW milestone against every assigned task and acceptance criterion.

Do not add new features. Inspect code, database migrations, tests, docs and Git diff. Verify every task's implementation, authorization, RLS, validation, responsive states, error handling, accessibility and tests. Run relevant lint/typecheck/unit/integration/E2E/build checks.

Update task statuses only when evidence exists. Mark unresolved items BLOCKED or PARTIAL, not DONE. Update TRACEABILITY.md with evidence. Identify regressions and security risks. Do not create a commit unless explicitly requested.

Return a milestone report: completed task IDs, incomplete/blocked IDs, files changed, test commands/results, security findings, performance findings, migration state, docs changed and recommended next task.
```
