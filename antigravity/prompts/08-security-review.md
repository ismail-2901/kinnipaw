# Prompt 08 — Security Review

```text
Perform a scoped security review of the requested KINNIPAW module.

Inspect authentication, object-level authorization, role/function authorization, ownership, organization membership, RLS, Storage policies, secrets, input validation, rate limits, file uploads, exact location handling, private health/application/message data, audit logs and AI data sharing.

Test allowed and denied cases with distinct user identities. Do not disable controls or use service credentials to bypass RLS. Report findings by severity with file/table/endpoint references and concrete remediation. Do not claim the application is secure based only on static review; distinguish tested from untested controls.
```
